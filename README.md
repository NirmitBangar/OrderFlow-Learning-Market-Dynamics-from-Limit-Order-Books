# OrderFlow

## Learning Market Dynamics from Limit Order Books

OrderFlow is a research project investigating whether machine learning
and deep learning models can learn predictive and transferable
representations from limit order book dynamics.

## Research Question

Can deep learning extract predictive and transferable representations
from limit order book dynamics?

## Objectives

- Understand limit order book dynamics
- Construct a clean market microstructure dataset
- Engineer meaningful microstructure features
- Establish statistical baselines
- Establish machine learning baselines
- Develop deep learning models
- Build a Transformer-based model
- Investigate self-supervised learning
- Study transfer across securities and market regimes
- Evaluate economic significance through backtesting

## Project Pipeline

Raw LOB Data
→ Data Exploration
→ Feature Engineering
→ Statistical Baselines
→ Machine Learning
→ Deep Learning
→ Transformer
→ Self-Supervised Learning
→ Transfer Learning
→ Economic Evaluation
